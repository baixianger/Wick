TRADINGFLOOR · REFERENCE STUDY · 2026-05-24

Agent workflows for a trading desk, three ways

What TradingAgents, live-trade-bench, and AI-Trader each teach us — and which ideas belong in Wick's TradingFloor.

TL;DR

Our pipeline-style TradingFloor is closest to TradingAgents; live-trade-bench validates a much thinner "one LLM → portfolio weights" loop; AI-Trader isn't really an agent at all but a SKILL.md + heartbeat platform — port the thin-agent primitive and the SKILL/heartbeat shape, keep the pipeline as an optional "deep analysis" mode.

Why this looks nothing like TradingAgents despite the name

It's a venue + social network for autonomous agents, not a reasoning engine. The "multi-agent" is multi-account, not multi-role; debate is across agents over time, not within one decision.

06

What to port into Wick

Ranked by leverage. Each links back to a concrete file or memory note.

Port · High leverage

Portfolio-weights as action primitive

live-trade-bench's cleanest idea: the LLM emits {TICKER: weight, "CASH": weight} summing to 1.0, the system liquidate-and-rebuys. Sidesteps order/fill/slippage entirely.

fits Wick's "thin agent" direction in memory/tradingfloor-agent-design.md; could live alongside the 5-tier Rating as a second output mode.

Port · High leverage

Self-conditioning via history-in-prompt

Inject the last N decisions + their realized returns back into the next prompt. Cheap stand-in for the reflection/RAG stack TradingAgents builds.

fits a per-portfolio history table; sidesteps vector store and on-device embedding.

Port · Medium leverage

SKILL.md as the capability contract

AI-Trader's pattern: every tool/skill is a markdown file with YAML frontmatter, agent fetches by URL at runtime. We already have TradingFloor/Skills/*.md — formalize the contract and let users add their own.

aligns with planned PiSwift chat mode + AgentTool registry.

Port · Medium leverage

Heartbeat loop instead of "press the button"

For users who want background monitoring: a local cron/Combine loop fetches typed events (price gap, news drop, earnings), enqueues them, the agent reacts. Same shape as AI-Trader's /heartbeat, but device-local.

consider only after fixed-flow + chat mode ship.

Keep · Don't import

LangGraph & checkpoint DB

Already trimmed. The Swift pipeline + AgentState blackboard is plenty. SQLite resume buys little for a single-run analysis.

skip unless we add long-running multi-day workflows.

Keep · Don't import

Server-side multi-agent social network

AI-Trader's leaderboard / copy-trade / team-missions surface assumes a hosted SaaS with retained user data. Wrong shape for a sold app where users bring their own keys.

skip — conflicts with memory/wick-business-model.md (BYO everything).

Concrete next step

Sequence the three thin-agent imports behind the already-planned interactive PiSwift runtime (task #7 in memory/tradingfloor-agent-design.md): (1) portfolio-weights output mode, (2) history-in-prompt self-conditioning, (3) formalized SKILL.md contract. Heartbeat loop after.
