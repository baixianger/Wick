# Bull / Bear Debate

Use this to pressure-test a position before committing. Requires the analysts'
findings (or at least a `get_market_data` snapshot) as input.

## Procedure

Run one or more rounds. Each round:

1. **Bull** — strongest evidence-based case to buy/hold. Rebut the prior bear
   points. Specific, no hype. 3–5 sentences.
2. **Bear** — strongest evidence-based case to sell/avoid. Rebut the prior bull
   points. Specific, no doom. 3–5 sentences.

After the final round, **weigh** the two: which side's evidence is stronger and
why. Name the single fact that would flip your view.

## Output

A short bull block, a short bear block, and a 2–3 sentence verdict with the
decisive factor.
